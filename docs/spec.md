# ChartSpec Specification (v0.1.0)

`ChartSpec` is the formal JSON-serializable specification contract of Vizora. All chart configurations, whether generated by `<AutoChart />`, authored by developers using `<Chart />`, or serialized over network protocols, strictly conform to this schema.

---

## Top-Level Schema

```typescript
export type ChartType = 'line' | 'bar' | 'scatter' | 'histogram' | 'kpi-sparkline';

export interface ChartSpec {
  $schema?: string;
  version: '0.1.0';
  type: ChartType;
  title?: string;
  subtitle?: string;
  data: Record<string, unknown>[];
  encoding: EncodingMap;
  config?: ChartConfig;
}
```

---

## Field Encodings

```typescript
export interface FieldEncoding {
  field: string;
  type?: 'quantitative' | 'temporal' | 'categorical';
  label?: string;
  format?: string; // e.g., '$,.2f', '%', 'YYYY-MM-DD'
}

export interface EncodingMap {
  x?: FieldEncoding;
  y?: FieldEncoding;
  color?: FieldEncoding;
  size?: FieldEncoding;
  orientation?: 'vertical' | 'horizontal'; // for Bar charts
  bins?: number;                           // for Histograms
}
```

---

## Chart Configuration

```typescript
export interface ChartConfig {
  width?: number;
  height?: number;
  margin?: { top: number; right: number; bottom: number; left: number };
  theme?: 'light' | 'dark';
  showGrid?: boolean;
  showLegend?: boolean;
  showTooltip?: boolean;
}
```

---

## Validation & Determinism Contract

1. **Validation:** Every `ChartSpec` is parsed and validated at runtime using `validateChartSpec(spec)`. If validation fails, an explicit `ChartSpecError` with actionable field suggestions is thrown.
2. **Determinism:** Given identical `ChartSpec` inputs, `createSceneGraph(spec)` outputs an identical `SceneGraph` tree across all execution environments.
